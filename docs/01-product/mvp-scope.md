# FORCAP MVP Scope

## MVP Objective

Build a working FORCAP Core and Engineering/PMS module that can demonstrate replacement of the most important PROP Engineering workflows.

## MVP Modules

- FORCAP Core
- FORCAP Engineering / PMS
- FORCAP Reports
- Basic Spares Link
- Admin / Access Control

## MVP Screens

- Login
- FORCAP Desktop
- Vessel Selector
- Vessel Workspace
- Engineering Dashboard
- Component Explorer
- PM Worksheet Templates
- Issued Worksheets
- Deferred Worksheets
- Complete Worksheet
- Chief Engineer Authorisation
- Completed Worksheet History
- Ad-hoc Maintenance
- Running Hours
- PMS Reports
- User Management
- Role / Access Management
- Audit Log

- Completed Worksheets by Job
- Overdue Worksheets

- Running Hours Sheet
