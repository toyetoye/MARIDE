# PMS MVP Build Priorities

## Purpose

This document defines the first PMS build slice for FORCAP.

## MVP Objective

Build enough of FORCAP PMS to demonstrate credible replacement of PROP Engineering's core planned maintenance workflow.

## P0 Scope

| Priority | Feature | Reason |
|---|---|---|
| P0 | Vessel Selector | Every PMS record is vessel-specific |
| P0 | Component Explorer | PROP Engineering is component-driven |
| P0 | Component Criticality | PROP reports group Critical and Significant components |
| P0 | PM Template Register | Needed to create issued worksheets |
| P0 | Issued Worksheet List | Core PMS active workload |
| P0 | Complete Worksheet Flow | Core shipboard workflow |
| P0 | Chief Engineer Authorisation | Required before final history |
| P0 | Deferral Workflow | Required to control due/overdue jobs |
| P0 | Completed Worksheet History | Required for audit and Class evidence |
| P0 | PMS Reports | Required to replace PROP reporting |
| P0 | Audit Logging | Required for trust and compliance |
| P0 | Role/Vessel Access | Required to avoid cross-vessel access |

## P1 Scope

| Priority | Feature | Reason |
|---|---|---|
| P1 | Running Hours | Required for hourly jobs |
| P1 | Ad-hoc Maintenance | Required for real maintenance history |
| P1 | Parts Used | Links PMS to spares |
| P1 | Attachments | Evidence support |
| P1 | Maintenance Forecast | Planning support |
| P1 | Excel/PDF Export | Familiar PROP replacement |
| P1 | PMS Dashboard | Better overview than PROP |
